# SIMD and multiversioning overview (lanes by the output type)

Static analysis (llvm-mca, cycles per 4096 output bytes), jix-py kernels. All configurations size
the contiguous loop's lanes by the output type (the MAX_ITEMSIZE change disabled):

- `A` (`cfg-A`): this branch: fearless_simd multiversioning (runtime dispatch) + the SIMD bodies
  of the scalar traits.
- `B` (`cfg-B`): `A` without the SIMD bodies (every `*_bulk` the scalar map, auto-vectorized).
- `noMV`: `A` (or `B`) without multiversioning: the plain x86_64 build's SSE2 code, which a
  build without runtime dispatch runs on every x86 CPU (`cfg-A-x86` / `cfg-B-x86`: simulated on
  all the x86 CPUs). i686 and aarch64 have a single level: their `noMV` is `A` / `B` itself.
- `main` (`main-x86`, `main-other`): the main branch, which also lacks this branch's other
  changes (e.g. the `map_inline` codegen fix): not multiversioning alone.

Generated by `compare.py`, e.g. `python jix/probe/compare.py A=cfg-A B=cfg-B`.
