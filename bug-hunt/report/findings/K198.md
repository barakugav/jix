# K198: Identity Slice / Flip / Roll and `&dyn ArrayStorage` pass their inner's ReadTiling::Fusable through (#106) without forwarding its pipeline, so a parent element-wise op reads untiled and pulls a temporary the size of the whole region

- Severity: low  Verdict: confirmed  Category: resource
- Location: jix/src/ops/shape_ops/slice.rs:229 (related: jix/src/ops/shape_ops/flip.rs:181, jix/src/ops/shape_ops/roll.rs:161, jix/src/storage/mod.rs:201, jix/src/storage/core_trait.rs:113, jix/src/storage/params.rs:1087, jix/src/array/read.rs:458, jix/src/storage/any.rs:108, jix/src/ops/transmute.rs:58)
- Reachability: public Rust API (Python is not affected: every Python result is an `ArrayAny`, which demotes Fusable to SinglePass at any.rs:108)
- Reported by: concept-read-contract
- Consolidated: found in run 2026-11-17-scan-106-107-b as F007; line numbers below are at c705a54 (#107). Re-run by hand at main c705a54 (#107): reproduces (repro_k198: reads through identity Slice / Flip / Roll and &dyn ArrayStorage pull region-sized temporaries). Current location: jix/src/ops/shape_ops/slice.rs:229.

## What goes wrong
#106 lets the top-level read skip tiling for anything classified ZeroCopy, Fusable or
SinglePass (array/read.rs:458). Fusable promises "a fused element-wise tree whose leaves are all
ZeroCopy ... with no temporary" (params.rs:1072-1084), and an element-wise parent trusts that
promise when it combines its inputs' classes (`ReadTiling::fused`, params.rs:1087). In the identity
case (a full-range step-1 Slice, a Flip of only length <= 1 dims, a Roll with shift 0 mod len),
Slice / Flip / Roll return `self.array.spec()` unchanged, so an element-wise inner stays Fusable.
The `&dyn ArrayStorage` forwarder (storage/mod.rs:201) does the same. None of these four overrides
`read_as_elementwise_pipeline`, so the parent's pipeline gets the default (core_trait.rs:113-125):
a `read_data_pull` of the WHOLE requested region into a pooled temporary. The result is still
Fusable, so nobody tiles it. Values are correct, but a full read of `-((-p).slice((.., ..)))`
allocates one extra region-sized buffer: peak memory doubles, where the same expression with a
non-identity forwarder is tiled and needs only ~128 KiB.

## Trigger
`p` = Plain f64 of shape [1, 2^21] (16 MiB). Each of these reports ReadTiling::Fusable:
- `-((-p).slice((.., ..)))`
- `-((-p).flip(0usize))` (dim 0 has length 1)
- `-((-p).roll(0, 1))`
- `-(Array::from_storage(&(-p) as &dyn ArrayStorage).into_typed::<f64>())`
Read the full region with `to_buf_slice` into a preallocated buffer (or with `to_ndarray`).

## Root cause
The identity fast paths (e6ef7ee, #95) make Slice / Flip / Roll transparent for `read_data`,
`spec()` and `as_compact()` (slice.rs:229-233, flip.rs:181-185, roll.rs:161-165), but not for
`read_as_elementwise_pipeline`. Before #106 that was harmless: element-wise ops cleared all flags
(`with_cleared_flags` at a7b0656 op1.rs:145), so the parent read was tiled and each tile's default
pull was tile-sized. #106 added the Fusable class and made `fused()` trust each input's class, and
it handled exactly this situation for the erased storages - `ArrayStorageAny` demotes with
`forwarded()` ("A parent can't fuse through the erased storage", any.rs:106-108), as does Transmute
(transmute.rs:58) - but the identity paths and `impl ArrayStorage for &dyn ArrayStorage`
(storage/mod.rs:176-215) were missed. These four are the only storages that return their inner's
spec unchanged without also forwarding the pipeline (IntoType, `&S` / `&mut S` / `Box` / `Rc` / `Arc`
and `impl_array_storage_forward!` forward both).

Related, same class but a different root cause: K192 (Select is classified Fusable but its
`read_data` pulls `condition` and `y` for the whole region).

## Suggested fix
Either make the classification match the read path - in the identity case return the inner's spec
with the tiling demoted by `forwarded()` (store a precomputed copy in `self.spec`; do the same in
`&dyn ArrayStorage::spec`) - or, better for speed, forward `read_as_elementwise_pipeline` in the
identity case (an Either-style pipeline over "inner pipeline" vs "default leaf") so the tree really
fuses. Add a test that a no-op view over an element-wise op reads with no region-sized temporary.
