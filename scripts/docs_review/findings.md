# Findings

What the review agents found and did not fix, collected per unit as the units are committed.
Nothing here was changed in the code or the docs.

- **Possible code bugs** - the code does something other than what its docs describe, and the
  docs look like the intended behavior. The review is not a bug hunt; these were met in passing.
- **Needs the maintainer** - a doc and the code disagree and it is not clear which is right, or
  a question only the author can answer.
- **Docs, not fixed** - a docs problem outside the unit that found it, or one the gate does not
  let an agent fix (docs generated by a macro).
